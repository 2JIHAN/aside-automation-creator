# 업무 작업계획 제출

계획 대상: workflow/steps/work.md

이미 공유된 필수 배경지식과 계획 대상 문서를 바탕으로 이번 업무를 어떻게 수행할지 실행 결과 폴더의 work-plan.md에 적습니다. 대상 문서는 계획할 자료이며 이번 턴에 실행하지 않습니다.

- 확인할 대상과 조회 범위, 읽을 자료와 적용할 권한.
- 실제 화면이나 입력에서 확인할 정보와 판단 순서.
- 결과를 남길 위치, 완료 조건과 확인하지 못한 업무 기준.

업무 순서와 판단을 자연어로 적습니다. 불필요한 JSON 필드나 저장 프로그램을 설계하지 않습니다. 실제 업무를 수행했거나 결과를 확인한 것처럼 쓰지 않습니다.

사이트 접속과 브라우저 조작, 원본 파일 조회와 처리, 외부 변경과 알림 전송은 하지 않습니다. 업무 파일은 work-plan.md만 작성하며 이월 메모와 업무 상태는 바꾸지 않습니다. 비공개 추론과 비밀값도 적지 않습니다.

마지막 줄은 상태: 계획완료 또는 사유와 함께 상태: 계획불가로 작성합니다.
