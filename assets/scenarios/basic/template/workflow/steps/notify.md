# 결과 알림

`__NOTIFY_METHOD__`로 `__NOTIFY_TARGET__`에 실제 업무 결과를 알립니다. 업무 실패를 성공으로 표현하지 않습니다.

## 중복 방지

이번 실행 ID를 중복 방지 키로 삼아 전송 기록과 제공자의 결과를 먼저 확인합니다. 이미 보냈으면 작성과 전송을 반복하지 않고 기존 결과만 확인합니다. 보내지 않았다는 것이 확실할 때만 한 번 전송합니다. 전송 여부가 불명확하면 재전송하지 않습니다. 전송 직전에 시도 기록을 남기고, 응답이 끊겼거나 전송 여부를 확인할 수 없으면 불명확으로 기록합니다. 제공자가 중복 방지 키를 지원하면 같은 키를 사용합니다.

대상과 전송 방법, 제목, 실제 확인 시각과 `__TIMEZONE__`, 업무 결과, 보고서 경로, 실패 이유와 필요한 사용자 조치를 확인합니다. 비밀정보나 파일 본문은 보내지 않습니다. 실제 전송된 결과의 대상, 내용과 시각을 대조하고 제공자의 메시지 ID 또는 수신 확인 등 해당 방법의 증거를 이번 턴 증거 폴더에 저장한 뒤 다시 읽습니다. 응답 성공 코드만으로 내용 검증을 대신하지 않습니다.

검토 후 복귀해도 같은 중복 방지 규칙을 적용합니다. 이미 보낸 내용이 잘못됐으면 임의 편집이나 재전송 없이 실패로 남깁니다. 증거만 부족하면 기존 전송의 증거만 보완합니다. 정리는 다음 단계에 맡깁니다.

- `알림완료`: 실제 전송 결과와 증거를 확인했습니다.
- `알림불가`: 전송 또는 검증을 끝내지 못했습니다.

이미 전송했는지와 미달 항목을 남깁니다. 마지막 줄은 `상태: 알림완료` 또는 `상태: 알림불가`로 작성합니다.
