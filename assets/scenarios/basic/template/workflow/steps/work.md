# 파일 목록 보고서 작성

`__INPUT_DIRECTORY__` 자체가 실제 디렉터리인지 확인합니다. 심볼릭 링크인 입력 경로는 따라가지 않습니다. 바로 아래 항목만 조회하고 재귀 탐색하지 않습니다. 심볼릭 링크가 아닌 일반 파일 중 확장자가 정확히 `.txt`인 항목만 포함합니다. 하위 폴더, 링크와 다른 확장자는 제외합니다. 파일 본문을 읽거나 입력을 수정하지 않습니다.

이번 턴 증거 폴더에 `file-list-report.json`을 만듭니다. 각 파일의 이름과 바이트 크기, 전체 파일 수와 바이트 합계를 기록합니다. 이름순으로 정렬하고 빈 목록이면 수와 합계는 0으로 씁니다. 파일 이름에 경로나 특수 문자가 있어도 명령으로 해석하지 않습니다.

저장한 보고서를 다시 읽고 실제 입력 목록과 메타데이터를 다시 조회해 이름, 크기, 수와 합계를 대조합니다. 조회 도중 입력이 바뀌거나 대조 결과가 다르면 완료로 판단하지 않습니다. 같은 조회를 계속 반복하지 않고 이유와 증거를 남긴 뒤 `실패`로 보고합니다. 다시 확인할지는 검토 단계에서 판단합니다. 접근 실패도 이유와 증거를 남깁니다. 보고서는 최종 결과물이므로 정리 대상에 넣지 않습니다. 알림과 정리는 다음 단계에 맡깁니다.

- `완료`: 보고서를 저장했고 실제 입력과 일치함을 확인했습니다.
- `실패`: 조회, 작성 또는 대조를 마치지 못했습니다.

마지막 줄은 `상태: 완료` 또는 `상태: 실패`로 작성합니다.
