# 이번 실행의 자원 정리

이번 실행에서 생성한 자원 목록과 생성 증거를 확인합니다. 이번 실행이 만들었다고 명시적으로 기록된 임시 파일과 도구 세션만 정리합니다. 경로와 식별자, 소유 실행 ID를 실제 대상과 대조한 뒤 허용된 종료 또는 삭제를 수행하고 결과를 확인합니다. 이미 정리된 자원은 다시 만들거나 반복 삭제하지 않습니다.

최종 보고서, 증거 폴더, 입력 파일, 사용자 자원과 다른 실행의 자원은 보존합니다. 경로를 확장해 상위 폴더를 지우거나 심볼릭 링크를 따라가지 않습니다. 소유자를 확인할 수 없으면 그대로 두고 정리 실패를 보고합니다. 정리할 자원이 없고 목록과 생성 기록이 일치하면 정리 완료입니다.

정리한 항목, 보존한 항목과 실패 이유를 증거로 남깁니다. 업무 결과와 전송 기록을 바꾸지 않습니다.

- `정리완료`: 정리 대상이 모두 정리됐거나 대상이 없음을 확인했습니다.
- `정리불가`: 정리 또는 소유 확인을 마치지 못했습니다.

마지막 줄은 `상태: 정리완료` 또는 `상태: 정리불가`로 작성합니다.
