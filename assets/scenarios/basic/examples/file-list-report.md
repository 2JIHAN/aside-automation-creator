# 파일 목록 보고서

매번 지정 폴더의 바로 아래에 있는 일반 `.txt` 파일의 이름, 바이트 크기와 개수를 보고받는 예입니다. 파일 본문을 읽지 않아도 되고 원본을 바꾸지 않습니다. 링크와 하위 폴더는 제외합니다.

`__INPUT_DIRECTORY__`, `__NOTIFY_TARGET__`, `__NOTIFY_METHOD__`, 계정과 시간대를 먼저 정합니다. 조회와 보고서 저장, 외부 전송에 대한 권한도 확인합니다. `work.md`는 이번 턴 증거 폴더에 보고서를 만들고 실제 입력을 다시 조회해 대조합니다. 보고서와 증거는 정리하지 않습니다.

입력 폴더가 없거나 접근할 수 없으면 검토하고 최대 두 번 재확인합니다. 해결하지 못하면 실패를 알린 뒤 이번 실행의 임시 자원만 정리합니다. 소유가 불분명한 자원은 남기고 실패 이유를 보고합니다.

테스트는 가짜 CLI와 임시 HOME으로 실제 공유 엔진의 분기와 제한을 검사합니다. 알림 중복 방지와 파일 처리, 자원 소유 판정 지침은 정적 계약으로 확인합니다. 실제 에이전트가 보고서를 정확히 작성하거나 메시지를 보낸다는 의미는 아닙니다. 실제 검증은 사용자가 승인한 폴더와 전송 대상에서 별도로 해야 합니다.
