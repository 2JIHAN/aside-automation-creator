# 예약 상품의 운영과 공개 노출 확인

## 업무

관리 화면에서 대상 상품이 운영 중인지 확인하고, 고객에게 보이는 예약 목록에도 노출되는지 확인합니다. 관리 화면에서 미노출로 확인한 대상만 다시 켤 수 있으며 다른 상품과 설정은 변경하지 않습니다.

## 적용한 흐름

1. 관리 화면에서 대상 상품의 운영 상태를 확인합니다.
2. 미노출 상품이 있으면 해당 상품만 켜고 전체 대상의 상태를 다시 확인합니다.
3. 공개 예약 목록에서 대상 상품이 모두 보이는지 확인합니다.
4. 확인하지 못했거나 조치가 실패한 경우 검토합니다. 로그인과 인증은 복구를 시도하지 않고 사용자 조치로 남깁니다.
5. 결과를 알리고 이번 실행에서 직접 연 탭만 닫습니다.
6. 학습이 허용된 예외 경로에서는 기록을 검토합니다.

관리 화면 확인, 상태 변경과 공개 목록 확인은 권한과 완료 조건이 달라 별도 스텝으로 나눴습니다. 알림을 이미 보냈는지 불명확하면 다시 보내지 않으며, 전송된 본문과 필요한 첨부가 보이는 증거까지 확인해야 알림을 마친 것으로 판단합니다.

## 검증한 범위

이 흐름은 네이버 예약 관리 화면과 공개 목록을 확인하고 Slack으로 알리는 실제 운영 절차를 바탕으로 합니다. 개별 고객의 계정, 업체 주소와 상품명은 포함하지 않았습니다. 새 대상에 적용할 때는 권한과 상품 식별, 실제 화면과 알림 수신자를 따로 검증합니다.
