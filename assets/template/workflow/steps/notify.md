# 결과 알림

__NOTIFY_TARGET__에 이번 실행 결과를 알립니다.

## 재확인 시

리뷰 후 돌아왔다면 이번 세션에서 이미 전송했는지 먼저 확인합니다.
이미 보냈으면 작성과 전송을 반복하지 않고 기존 메시지의 내용, 첨부와 증거만 재확인합니다.
미전송이 확실할 때만 한 번 전송합니다. 전송 여부가 불명확하면 재전송하지 않습니다.
이번 실행에서 직접 연 알림 탭이 남아 있으면 그 탭을 사용합니다.

## 수행 방법

1. 수신자와 대화 또는 전송 대상을 확인하고 아래 양식을 작성합니다.

[Aside발신] __AUTOMATION_NAME__
확인 시각: {YYYY-MM-DD HH:mm 형식의 실제 날짜와 시각, __TIMEZONE__}
상태: {확인한 결과와 특이사항}
조치 내용: {실제로 수행한 조치와 결과}
필요한 조치: {사용자에게 필요한 조치}

별도 조치 없이 정상이면 상태까지만 씁니다. 문제나 복구가 있으면 조치 내용과 관련 증거사진을 첨부합니다.
사용자 조치가 없으면 해당 항목은 생략합니다. 업무가 해결되지 않았다면 정상으로 표현하지 않습니다.

2. 전송 전에 작성한 머리말, 날짜와 시각, 시간대, 사실에 맞는 내용과 필요한 첨부를 확인한 뒤 한 번 전송합니다. 한자 변환이나 입력 누락도 확인합니다.
3. 실제 전송된 메시지와 필요한 첨부를 같은 기준으로 대조합니다.
4. 증거를 저장한 뒤 이미지를 직접 열어 메시지 본문과 확인 시각이 보이는지 확인합니다. 화면 상단만 찍혔거나 본문이 잘린 이미지는 증거로 인정하지 않습니다. 필요하면 캡처만 다시 합니다.

이미 전송했거나 전송 여부가 불명확하면 재전송하지 않습니다. 탭은 정리 단계에 맡깁니다.

## 상태 보고

- 알림완료: 업무의 성공 여부와 관계없이, 수신자와 정확한 내용 및 날짜와 시각, 필요한 첨부, 전송 확인, 본문이 보이는 증거 저장과 재확인을 모두 완료했습니다.
- 알림불가: 위 조건 중 하나라도 충족하지 못했습니다. 이미 전송했더라도 내용 오류가 남거나 유효한 증거가 없으면 알림불가입니다.

전송 성공만으로 알림완료로 보고하지 않습니다. 미달한 항목과 이미 전송했는지를 설명합니다.
마지막 줄은 상태: 알림완료 또는 상태: 알림불가로 작성합니다.
